# Challenge 1 — Sum of Digits

## Problem Statement

Write a JavaScript program that reads an integer from standard input and prints the sum of its digits.
Don't change function name in template when writing solution. 

## Input Format

A single line containing one integer, `num`.

## Output Format

A single integer: the sum of all digits in `num`.

## Constraints

- `0 <= num <= 10^9`
- Input is guaranteed to be a valid non-negative integer.

## Example

**Input**
```text
5832
```

**Output**
```text
18
```

**Explanation**
`5 + 8 + 3 + 2 = 18`
